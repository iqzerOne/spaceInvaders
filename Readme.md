# Space Invaders на Python + Pygame
Есть меню, победа/поражение, счёт и т.д.
## Как запустить
```bash
pip install pygame
python space.py
```
## Управление
1. Стрелки влево/вправо
2. Пробел — стрельба
3. P / Esc — пауза
## Что реализовано
- Главное меню
- Движение игрока и врагов
- Стрельба игрока и врагов
- Система жизней и счёта
- Экраны победы и поражения
- Пауза
